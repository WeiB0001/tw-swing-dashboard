排名依據：歷史勝率優先，技術分數只是分層特徵

首頁名次的第一順位是歷史平滑勝率，不是技術分數。做法是： 先用技術面把每檔標的歸類成「型態 ＋ 分數級距」（例如「帶量突破 ＋ 65–75 分」）， 再去查回測資料裡同一類訊號歷史上贏過幾次。

排序順位：期望值 EV → 平滑勝率 → Profit Factor → 平均最大回撤 → 技術分數。 EV = 勝率×平均獲利 ＋ 敗率×平均虧損（已扣成本）。 EV ≤ 0 的標的會降到有正 EV 的之後，但不會被刪除，仍看得到名次。
查表順序：大盤狀態＋型態＋分數級距 → 型態＋分數級距 → 分數級距 → 樣本不足。
可信度：N<30 樣本不足、30–59 ★★、60–119 ★★★、120–249 ★★★★、≥250 ★★★★★。
勝率平滑：(勝場 + 10) / (樣本 + 20)，避免「3 戰 3 勝 = 100%」這種假訊號。
樣本門檻：型態層需 30 筆，不足退回只看分數級距；再不足就標示 樣本不足，以先驗 50% 計入排名並改用技術分數決定先後——不會生一個假勝率出來。
